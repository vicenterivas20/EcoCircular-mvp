# EcoCircular MVP 1.0 Final

Sistema Inteligente de Gestión de Cumplimiento Ambiental.

## Contenido del proyecto
- `index.html`: página principal.
- `css/style.css`: diseño visual.
- `js/`: lógica del sistema, Gemini, PDF, Excel y almacenamiento.
- `assets/logo.svg`: logo vectorial limpio para la versión MVP.

## Cómo probar
1. Extraer el ZIP completo.
2. Abrir `index.html` en Chrome.
3. Crear un proyecto.
4. Subir una RCA o resolución en PDF.
5. Pegar API Key de Gemini.
6. Generar propuesta de obligaciones.
7. Revisar y exportar Excel.

## Nota profesional
Esta es una versión MVP. Los datos se guardan en el navegador. Para uso comercial se recomienda implementar login, base de datos y backend seguro.
